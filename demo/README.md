## 2. 关于视频体积

**原始 mp4 分别 213 MB / 153 MB**，合计 367 MB——**超过 GitHub 单文件 100 MB 限制，无法直接 push**。

### 解决方案（任选其一）

#### 方案 A：使用 Git LFS

```bash
git lfs install
git lfs track "demo/*.mp4"
git add .gitattributes
git add demo/
git commit -m "demo: add screen recordings via LFS"
git push
```

> ⚠️ GitHub LFS 免费额度：1 GB 存储 + 1 GB/月带宽。两个视频已 367 MB，后续更新容易顶到上限。

#### 方案 B：外链托管（评审侧最稳）

把 mp4 上传到**网盘 / B 站 / YouTube**（分享链接可见），在本表填写：

| 段 | 外部链接 |
| :-: | --- |
| 段 1（1'31"） | `<填写>` |
| 段 2（2'08"） | `<填写>` |

#### 方案 C：提交包直传（最低成本，推荐）

**不做任何 LFS / 外链配置**——直接把 zip 原包上传到大赛系统的"演示材料"附件栏：
`屏幕录制 2026-09-24 033329.zip`（位于微信接收目录）。

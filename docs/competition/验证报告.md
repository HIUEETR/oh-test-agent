## 八、当前限制（如实披露）

1. **DevEco Testing 测试工程模式**：`not_validated`（Hypium Driver 模式已真实验证）
2. **压测脚本生成器**：L2 迭代中（已有稳定性压测执行入口）
3. **页面签名稳定性**：VLM 标题变化会影响签名，目前仅作快照证据而非去重键
4. **无稳定 key/id 的控件**：降级为坐标执行，并在代码 / 元数据 / Web 中持续告警
5. **资产流水线降级**：不产出 Hypium 脚本与回放证据；回归需求 Profile 引导
6. **API 鉴权**：当前是本机开发服务，没有鉴权，**不应直接暴露到不受信任网络**
7. **多机型矩阵**：当前仅 1 设备 1 分辨率验证，多设备并行仅在 §3.2 设计层
8. **VLM 缓存指标**：由兼容服务决定，项目侧不统计缓存命中率

## 九、复核方式

```bash
# 1. 克隆并安装
git clone https://github.com/HIUEETR/oh-test-agent.git
cd oh-test-agent
uv sync --all-groups
cp .env.example .env   # 填入模型 / HDC 配置

# 2. 预检（10 秒）
uv run main.py preflight

# 3. 运行真实 Agent（约 1-3 分钟）
uv run main.py run --provider openai \
  --task "打开知乎++，进入搜索，输入 OpenHarmony，返回首页"

# 4. 单独回放（3 次）
uv run main.py generate --run-id <run-id>
uv run main.py execute --run-id <run-id> --attempts 3

# 5. 启动 Web 控制台（另开终端）
uv run main.py dev
# 浏览器打开 http://127.0.0.1:15173
```
